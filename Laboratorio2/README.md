# Laboratorio Java - Grade Manager

Proyecto terminado según las hojas del laboratorio.

## Requisitos

- Java JDK instalado.
- Visual Studio Code.
- Extensión "Extension Pack for Java" de Microsoft (recomendada).

## Estructura

LaboratorioJava/
├── Main.java
└── grades/
    └── GradeManager.java

## Ejecutar desde Visual Studio Code

1. Abre la carpeta `LaboratorioJava` en Visual Studio Code.
2. Abre `Main.java`.
3. Pulsa el botón ▶ Run Java.

También puedes ejecutar desde la terminal:

```bash
javac grades/GradeManager.java Main.java
java Main
```

## Opciones

1. Agregar nota.
2. Ver promedio.
3. Ver número de notas aprobadas (>= 50).
4. Salir.
5. Eliminar una nota por posición o por valor.
